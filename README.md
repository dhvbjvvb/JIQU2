# 即取（喜欢的话也可以多多推广，或者点一个Star）
## 一款Android多平台媒体解析与下载工具

# 支持的平台有：今日头条，快手，抖音，微信视频号，即梦，豆包，哔哩哔哩，皮皮搞笑，皮皮虾，微博，最右，红果短剧，红果漫剧，好看视频，西瓜视频，全民K歌
若不清楚一些应用如何复制链接，请去设置中查看“解析教程与支持”板块
