## JIQU2
一款Android媒体解析与下载工具。

- 目前已经支持豆包、即梦、快手、抖音、微信视频号、皮皮搞笑（后续会逐步完善......）
- 若不清楚一些应用如何复制链接，请去设置中查看“解析教程与支持”板块

## UI界面（如果不喜欢默认的apple风格底栏的话，可去设置主题与外观中关闭悬浮底栏开关）

## 当前版本

`2.0.8`（内部版本号：`2008`，递增自 `2.0.7 / 2007`）

## 功能

- 解析支持的平台链接并预览媒体
- 下载视频、图片和音频
- 下载历史记录
- 下载完成通知
- 深色模式、主题色与悬浮底栏设置
