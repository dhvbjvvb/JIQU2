## JIQU2
一款Android媒体解析与下载工具。

- 目前已经支持皮皮虾、小红书、最右、今日头条、豆包、即梦、快手、抖音、微信视频号、皮皮搞笑
- 若不清楚一些应用如何复制链接，请去设置中查看“解析教程与支持”板块

## 当前版本

`2.1.0`（内部版本号：`2010`，递增自 `2.0.9 / 2009`）
本次主要修复和完善了以下问题：

1. 平台适配范围增加

- 新加入皮皮虾、小红书、最右、今日头条

2. 修复微信视频号无法下载问题

修复了点击下载后进度不动、无法真正下载的问题：

- 修正下载任务启动流程
- 增加真实下载进度回调
- 完善网络流读取和文件写入

3.修复视频预览状态显示不准确
改为：

- 封面可以先显示
- 视频首帧未到达前，覆盖真实的媒体流连接提示
- 视频首帧成功渲染后，才切换到真实视频画面
- 预览失败时显示“暂时无法预览，可直接下载”

4. 修复拖动进度条不跟手问题

- 修复了视频和音频预览拖动时，播放器组件不能真实反馈进度

5.优化请求结构，解析速度大大加快
- 清除不必要的冗余💩山代码

## 功能

- 解析支持的平台链接并预览媒体
- 下载视频、图片和音频
- 下载历史记录
- 下载完成通知
- 深色模式、主题色与悬浮底栏设置
