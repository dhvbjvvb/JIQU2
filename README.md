## JIQU2
一款Android媒体解析与下载工具。

- 目前已经支持豆包、即梦、快手、抖音、微信视频号、皮皮搞笑（后续会逐步完善......）
  
-若不清楚一些应用如何复制链接，请去设置中查看“解析教程与支持”板块

## 功能

- 解析支持的平台链接并预览媒体
- 下载视频、图片和音频
- 下载历史记录
- 下载完成通知
- 深色模式、主题色与悬浮底栏设置
- 关于页面提供项目开源地址
- 启动时通过 CDN 加速访问 GitHub Releases 静默检查更新
- 发现新版本后可选择 GitHub 应用内下载安装，或复制蓝奏云提取码并在浏览器手动下载
- GitHub 应用内下载完成后会校验包名、版本号和签名，再打开系统安装器
