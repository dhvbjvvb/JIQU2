# JIQU2
## 一款Android多平台媒体解析与下载工具。

- 目前已经支持皮皮虾、小红书、最右、今日头条、豆包、即梦、快手、抖音、微信视频号、皮皮搞笑、哔哩哔哩
- 若不清楚一些应用如何复制链接，请去设置中查看“解析教程与支持”板块

# 当前版本

`2.1.1`（内部版本号：`2011`，递增自 `2.1.0 / 2010`）

本次主要修复和完善了以下问题：

# 即取 2.1.1 更新内容

1. 新增哔哩哔哩视频无水印解析与下载支持。

2. 优化全部平台的文件大小识别与显示逻辑。

3. 优化大文件下载，根据文件大小自动调整并发线程与分段策略，提升 2GB 以上文件的下载速度，并改善下载末段速度过慢的问题。

4. 优化大文件存储方式，减少临时文件占用，同时保留兼容性回退机制。

5. 其他下载稳定性与界面细节优化。

# 功能

- 解析支持的平台链接并预览媒体
- 下载视频、图片和音频
- 下载历史记录
- 下载完成通知
- 深色模式、主题色与悬浮底栏设置
