# 即取
## 一款Android多平台媒体解析与下载工具。

- 目前已经支持皮皮虾、小红书、最右、今日头条、豆包、即梦、快手、抖音、微信视频号、皮皮搞笑、哔哩哔哩
- 若不清楚一些应用如何复制链接，请去设置中查看“解析教程与支持”板块

# 当前版本： 2.1.2

# 本次主要修复和完善了以下问题：
 即取 2.1.1 更新内容

- 1.增加自定义界面大小调节（避免自适应过大、放大或缩小）

    可在设置→主题与外观中进行调节

- 2.增加历史解析预览封面图（更方便记忆，寻找历史记录）

    视频有封面的话，会采取视频封面，如果没有封面的话，就采取视频首帧作为封面图

- 3.修复输入法键盘弹出问题（修复手动输入粘贴链接情况下会二次弹出输入法键盘）

- 4.悬浮底栏长按左右拖动更跟手（貌似没什么用）

- 5.修复底部板块之间切换后偶尔闪烁白屏问题

# 功能

- 解析支持的平台链接并预览媒体
- 下载视频、图片和音频
- 下载历史记录
- 下载完成通知
- 深色模式、主题色与悬浮底栏设置
